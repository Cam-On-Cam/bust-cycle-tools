Privacy Policy

Last updated: 2026-11-11

What the app is. Bust Cycle Tools is a personal tool used by the owner of the YouTube channels it connects to. It is not offered to the public.

What it accesses. After the channel owner signs in with Google, the app uses read-only access to the owner's own YouTube channel data and YouTube Analytics reports (YouTube Data API, YouTube Analytics API and YouTube Reporting API). It does not post, edit, or delete anything on any channel.

How the data is used. The data is used only to build the owner's private analytics dashboard and reports. It is stored on the owner's own computer. It is not sold, shared, or given to any third party, and it is not used for advertising.

Google user data. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion. The owner can delete the stored data at any time by deleting the files on their computer, and can revoke the app's access at any time at myaccount.google.com/permissions.

Contact. Questions can be sent through the YouTube channel @MotorMetricHQ.
